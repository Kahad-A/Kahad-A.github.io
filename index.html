Detecting Facial Emotions Using Convolutional Neural Networks

Since most emotional communication occurs through facial expressions and other visual cues, it is crucial to accurately interpret facial signals. Facial expression recognition is therefore vital in human-machine interaction. Consequently, accurately identifying facial emotions is critical in developing emotionally intelligent machines that can engage in more natural and effective interactions with humans. This can be helpful in understanding human behavior, diagnosing mental disorders, and improving virtual assistants for customer-facing businesses. The project intended to build a model that accurately detects facial emotions using Deep Learning and Artificial Intelligence techniques. The dataset consists of three sets: training, validation, and test, each with varying sizes. Each set contains four classes: happy, sad, neutral, and surprise. After performing exploration data analysis (EDA), the training set is the largest, with 15,109 images, and appears almost unbalanced. The validation set is imbalanced, whereas the test set is balanced, with 32 images per class. Convolutional neural networks and pre-trained or transfer learning techniques, such as VGG16, ResNet, and EfficientNet, were utilized in this project.
